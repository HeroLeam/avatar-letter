# 🎨 Avatar Letter

**Avatar Letter** é um sistema web leve e moderno para a criação de avatares tipográficos personalizados. Desenvolvido com **HTML5, CSS3 e JavaScript puro**, permitindo total controle sobre cores, fontes, textos e tags adicionais de forma totalmente interativa.

![Preview do Projeto](https://img.shields.io/badge/status-ativo-success) ![Licença MIT](https://img.shields.io/badge/license-MIT-blue)

---

## ✨ Funcionalidades

* **Personalização de Texto:** Escolha o texto principal do avatar (recomendado de 1 a 3 caracteres).
* **Cores Customizáveis:** Defina manualmente ou gere cores aleatórias para o fundo e para a letra.
* **Seleção de Fontes:** Várias opções de fontes tipográficas modernas e clássicas (com botão de aleatoriedade).
* **Tag NSFW Opcional:** Adicione uma tag flutuante customizável (ex: *NSFW*) com controle de texto, cor personalizada (`#ff3399` por padrão), tamanho e escolha de posição em qualquer um dos 4 cantos da imagem.
* **Exportação em Alta Resolução:** Baixe o avatar gerado diretamente em formato PNG de alta qualidade (`512x512px`).
* **Design Responsivo:** Interface limpa e agradável com tema escuro.

---

## 🚀 Como Executar

Por ser um projeto puramente frontend (HTML, CSS e JS), você não precisa instalar nenhuma dependência ou servidor Node.js complexo.

1. Clone o repositório ou baixe os arquivos (`index.html`, `style.css` e `script.js`) para uma pasta no seu computador.
2. Abra o arquivo **`index.html`** em qualquer navegador web moderno (Chrome, Firefox, Edge, etc.).

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Estrutura semântica e Canvas API para renderização de imagem)
* **CSS3** (Variáveis CSS, Flexbox, Grid e Design Responsivo)
* **JavaScript (ES6+)** (Manipulação de DOM, estado e lógica de exportação)
* **Google Fonts** & **FontAwesome**
